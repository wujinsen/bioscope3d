## 段内动态

| 维度 | 观察 | 解读 |
|---|---|---|
| 重心稳定性 | 每段内 cx/cy 抖动 < 0.05 | **每段几乎不平移**，是「站立式」展示 |
| 剪影面积稳定性 | 每段内面积抖动 < 3% | **没有 zoom in/out**，机位距离不变 |
| 主色稳定性 | 每段内 RGB 欧氏距离 < 10 | **微弱自转**（颜色不剧烈变） |
| 切镜锐度 | 1 帧之内完成 | **硬切**，非淡入淡出 |

→ 每段是「**固定机位 + 慢速小幅自转**」，不是「环绕飞行」。这点和 Hunyuan 视频的三镜头 + 大幅 orbit 完全不同。

## 含义（产品层）

1. 这段视频是产品的「**演示 / 营销 / 录屏**」素材，不是用户操作记录
2. 真正的产品交互 UI 在另一处（参考图 `Cell Architecture Studio`）
3. 但视频里**藏的是产品功能脚本**：
   - 多细胞库（7+）
   - 自动巡游（Auto Tour）
   - 每细胞独立机位预设和驻留时长
   - Cinema 模式（无 UI 全屏）
   - 顶级 PBR + HDRI 渲染
4. 这些功能在功能清单里编号为 **F01 – F08**（见 [03-features.md](./03-features.md)）
