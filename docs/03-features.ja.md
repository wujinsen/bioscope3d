| ID | 機能 | v1 出典 | 価値 | 優先度 |
|---|---|---|---|---|

### F58 詳細仕様

```
3 段階（デフォルト表示）:    Domain · Kingdom · Cell type
  Plant Cell:       Eukarya · Plantae   · Plant Cell
  Bacterium:        Bacteria · —         · Bacterium
  Neuron:           Eukarya · Animalia  · Neuron
  Red Blood Cell:   Eukarya · Animalia  · Erythrocyte
```

将来の拡張に備え 8 段階（Domain · Kingdom · Phylum · Class · Order · Family · Genus · Species）に下げて表示可能。該当しない段階は "—" を表示。

### F57 詳細仕様

```
状態ドットの色:
  グレー · Raw GLB         (ロード直後、未処理)
  黄色  · AO Baking        (PBR パイプラインがベイク中)
  緑色  · PBR Enhanced     (ベイク完了、強化版でレンダリング中)
  シアン · Compare Ready    (Diff モード：左が裸 / 右が強化)
パルス速度はレンダリング負荷に連動、速いほどリアルタイムに近い。
```

## 難度の凡例

- 🟢 直接的なフロントエンド設定 / 標準的な React コンポーネント
- 🟡 Three.js / シェーダ / ステートマシンが絡む、中程度のカスタマイズ
- 🔴 アルゴリズム / 後処理パイプライン / データ前処理が必要、専門設計が必要

## 依存関係（主要）

```
F35 (小器官分離)  ─┬──→ F26 Isolate
                   ├──→ F27 Hide Others
                   ├──→ F33 hover/click ハイライト
                   └──→ F25 Cross-Section（特定器官への精密切断）

F16 (PBR エンハンス) ─┬──→ F06 最上級レンダリング（強化後 Tripo 動画にさらに近づく）
                     └──→ F49 ワンクリック切替

F02 (自動ツアー)   ─┬──→ F03 駐留時間設定
                   ├──→ F05 カメラプリセット
                   ├──→ F12/F17/F18/F19 制御
                   └──→ F22 パス

F31 (メタデータ)   ─┬──→ F32 小器官
                   ├──→ F34 Notes
                   └──→ F36 Where it Occurs
```

## 実装戦略

- **まず P0 + F35 に依存しない P1 を出す** → MVP v1 を形成（機能のおよそ 60%）
- **F35（小器官分離）は単独のパイプライン実験として進める**、可行性検証後に統合 → MVP v2
- **F48（AI API）** 現段階はモック、本接続は将来 → メインラインを阻まない
- **F54–F63 の v1 翻案機能** → P1 はすべて v2、P2 はすべて v3 に投入
