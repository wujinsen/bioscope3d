## セグメント内ダイナミクス

| 指標 | 観測 | 解釈 |
|---|---|---|
| 重心安定性 | 各セグメント内で cx/cy のジッタ < 0.05 | **セグメント内はほぼパンしない**、「静置プレゼン」スタイル |
| シルエット面積安定性 | 各セグメント内で面積ジッタ < 3% | **ズーム イン / アウトなし**、カメラ距離は固定 |
| 色安定性 | 各セグメント内で RGB ユークリッド距離 < 10 | **微妙な自転**（色は大きく変わらない） |
| カットの鋭さ | 1 フレーム内で完了 | **ハードカット**、フェードなし |

→ 各セグメントは「**固定カメラ + 低速な小振幅自転**」であり、フライバイオービットではない。これは Hunyuan 系の 3 ショット + 大きなオービット動画とは全く別物。

## パレット（K-means × 12）

動画から均等サンプリングした 6 枚のフルレゾフレームから抽出：

| 色値 | 比率 | 推定用途 |
|---|---|---|
| `#f4f1e2` `#f6f3e4` `#f0ebdd` `#f7f1e3` `#f4efe1` `#f4f0e5` | **53 %** | **クリームペーパー背景**（HDRI 主色） |
| `#ebe7d9` `#e2ddd0` | 20 % | 背景グラデーションの中間段 |
| `#c6beb8` | 5 % | 背景グラデーションの深い段 |
| `#a19698` | 6 % | ニュートラルグレー / 影 |
| `#8a7a5e` | **6 %** | **暖アンバー**（細胞小器官の主色） |
| `#4b474b` | 4 % | 深い影 |

**全体の質感**：暖白ベース + 暖灰の影 + 暖アンバーのアクセント、**雑誌 / 教科書 / 標本カード**の質感。
**冷紫もディープな黒もない** —— 以前「moody dark」と判定したのは誤り。

## UI が存在しない証拠

外周 5% の領域における輝度統計 + 勾配検出：

| 領域 | 端の輝度平均 | 中央の輝度平均 | 強い勾配スパイク |
|---|---|---|---|
| 上 5 % | 226 | 188 | 1 か所のみ（H=1、画面トップ最初の行） |
| 下 5 % | 230 | 188 | 1 か所のみ（H=H-1） |
| 左 5 % | 224 | 172 | 0 |
| 右 5 % | 232 | 172 | 0 |

→ 端が明るいのは**HDRI グラデーション自体**（背景は周辺が明るく、中央はモデルに遮られて暗い）であり、UI パネルではない。**動画には本当に UI がない。**

## 含意（プロダクト層）

1. この動画はプロダクトの「**デモ / マーケティング / 画面録画**」素材であって、ユーザー操作の記録ではない。
2. 実際の製品インタラクション UI は別の場所にある（リファレンス画像 `Cell Architecture Studio`）。
3. ただし動画は**プロダクト機能スクリプトをエンコードしている**：
   - 複数細胞ライブラリ（7+）
   - 自動ツアー（Auto Tour）
   - 細胞別の個別カメラプリセット + 駐留時間
   - Cinema モード（UI なしフルスクリーン）
   - 最上級 PBR + HDRI レンダリング
4. これらは機能リストで **F01 – F08** に対応（[03-features.md](./03-features.md) 参照）。
